# Contributing to AurOS

Outside code is **not being accepted yet**: the project is run by one person with AI assistance, and
there is no process for reviewing or licensing other people's changes. Bug reports and questions are
welcome as issues on the project page (they are public and permanent: never put passwords, recovery
keys or private files in one). To report a security problem privately, see `SECURITY.md`.

If that changes: contributions will come under the MIT license (`LICENSE`) and need a
`Signed-off-by` line under the Developer Certificate of Origin 1.1 (https://developercertificate.org/);
there will be no contributor license agreement. Files under `tools/scamtest` and
`tools/fuzz/corpus/font` keep their own licenses (see the `NOTICE` files there).
