Going back to Windows

Windows is still on this computer, with your files from before.

In the first days

While AurOS is new, it asks you each time it starts whether everything works. Each answer does one thing:

Yes, it all works
AurOS starts every time from now on. Windows and its files stay on this computer.
Let me look first
Nothing changes. AurOS asks again the next time it starts.
No, go back to Windows
Windows starts the next time this computer starts. AurOS stays on this computer, with anything you saved in it. Nothing is deleted.

Remove AurOS and put Windows back

This removes AurOS and gives Windows all of its space back. Anything you saved in AurOS goes with it.

  1. Copy anything you saved in AurOS and want to keep onto a memory stick.
  2. Press Settings at the bottom of the screen, then Put Windows back.
  3. Press Remove AurOS and put Windows back. It asks you to press it again, to be sure. Press it again.
  4. This computer restarts and removes AurOS. Leave it switched on and plugged in until Windows has started.

After you pressed No, go back to Windows, AurOS is still on this computer, but Windows starts. To use AurOS again, or to remove it, ask someone who knows computers. They can start AurOS from this computer’s start-up menu.

When you have finished reading, press Close this at the bottom of the screen.
