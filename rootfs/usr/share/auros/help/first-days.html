“Does everything work?”

While AurOS is new, it asks you each time it starts whether everything works. Each answer does one thing:

Yes, it all works
AurOS starts every time from now on. Windows and its files are meant to stay on this computer.
Let me look first
Nothing changes. AurOS asks again the next time it starts.
No, go back to Windows
Windows starts the next time this computer starts. AurOS stays on this computer, with anything you saved in it. Nothing is deleted.

Yes and No each ask once more before they do anything, so a slip of the hand changes nothing. Not yet goes back to the question.

After you pressed No, go back to Windows, AurOS is still on this computer, but Windows starts. To use AurOS again, or to remove it, ask someone who knows computers.
