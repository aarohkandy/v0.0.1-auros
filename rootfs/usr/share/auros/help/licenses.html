Licenses and the source code

AurOS is made of free software, written by many people. You may use it and share it, and you may have its source code.

The licenses

Every program on this computer comes with a license, a short text that says what you may do with it. They are kept on this computer, in the folder called /usr/share/doc: each program has its own folder there, with a file called copyright inside. The notices that AurOS adds are in the folder called /usr/share/doc/auros. If you want to read them, ask someone who knows computers to show you.

Programs you add with Get more programs show their license on their page in the store.

The source code

You may have the source code of the programs in AurOS, free of charge. Each AurOS release has a second release beside it on the AurOS project page on the internet, with the source code in it. The AurOS website has a page called Licenses and source code that says where.

If you would rather not use the internet, write to CONTACT_EMAIL. Say which AurOS you have. We will send you the source code on a memory stick or a disc, for no more than the cost of the stick or disc and the postage.
