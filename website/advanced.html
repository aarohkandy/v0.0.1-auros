For someone who knows computers

AurOS Setup stopped on this computer for a reason that someone comfortable with Windows’ settings can usually fix in under an hour. Setup has not changed anything. This page is for that person.

If that isn’t you, you can stop here and keep using Windows as it is. Show this page to someone you trust who knows computers.

First, for any of these fixes

Each fix is an ordinary Windows or firmware change, made with Windows’ and the computer maker’s own tools, not with AurOS. No change to how a computer starts is free of risk. So:

  1. Copy the files that matter (photos, documents, anything that can’t be replaced) to a memory stick or another drive. Check that the copies open.

  2. If BitLocker or Device encryption is on, find the recovery key first. After a firmware change, Windows asks for the 48-digit recovery key at the next start unless protection is paused. Control Panel → BitLocker Drive Encryption shows whether it is on. Press Back up your recovery key, and keep the key somewhere other than this computer. Then press Suspend protection.

    Before each restart in these steps, look again: if it says Suspend protection, press it. When everything is done, press Resume protection. Windows Home’s Device encryption has no pause button: have the recovery key ready instead, and type it in when Windows asks.

  3. Know how to open the firmware settings (the “BIOS setup”). Usually it is a key pressed straight after switching on: F2, Del, F10, F1 or Esc, depending on the maker. The logo screen often says which. On a computer that already starts the newer way, Windows has its own route: Settings → System → Recovery (Windows 10: Update & Security → Recovery) → Advanced startup → Restart now, then Troubleshoot → Advanced options → UEFI Firmware Settings.

  4. Have the Windows account’s password ready, not only its PIN. Safe Mode sometimes asks for the password.

Windows says Smart App Control blocked AurOS Setup

Read this before switching it off

Smart App Control checks every program before it runs, so switching it off takes away real protection. Since April 2026, Windows can switch it back on from the same page. A Windows update in October 2026 stopped that from working on some computers, and on those it may stay off. If that isn’t acceptable, stop here and keep using Windows. Nothing has been changed.

Windows said: “Smart App Control blocked an app that may be unsafe”Smart App Control is on some newer Windows 11 computers. It blocks a program that has no company signature unless Microsoft already knows it, and it has no Run anyway. AurOS Setup has no signature yet: the AurOS project is applying for a free one (see the code signing policy). Windows 10 has no Smart App Control.

The switch

  1. Press Start, then Settings → Privacy & security → Windows Security → App & browser control.

  2. Press Smart App Control settings, and choose Off. Confirm if Windows asks.

  3. Run AurOS Setup again from the Downloads folder.

This computer is set to start only Windows

Setup said: “This PC is set to start only Windows”Secure Boot on this computer trusts Microsoft’s key for Windows, but not Microsoft’s key for other software. AurOS starts through the same Microsoft-signed start-up files Ubuntu uses, which are signed with that second key. Some Secured-core computers come set this way.

Leave Secure Boot on. One firmware setting adds the second key.

The switch

  1. Do the steps in First, for any of these fixes. Pausing BitLocker matters here: this change always makes Windows ask for the recovery key otherwise.

  2. Open the firmware settings through Windows: Settings → System → Recovery → Advanced startup → Restart now → Troubleshoot → Advanced options → UEFI Firmware Settings.

  3. Under Security, then Secure Boot, switch on Allow Microsoft 3rd Party UEFI CA. Surface calls it Microsoft & 3rd party CA; Dell calls it Enable Microsoft UEFI CA. Leave Secure Boot on. Save and exit (often F10).

    A sketch. Every maker’s screen looks different: look for the name of the setting.

  4. Windows starts as before. Run AurOS Setup again from the Downloads folder.

If Windows asks for the BitLocker recovery key

Type the key you found in the first step. Windows then starts as before, and stops asking.

If Setup said “This PC needs a newer AurOS installer” instead, there is nothing to change on this computer. This copy of AurOS Setup is too old for it. Download AurOS Setup again later.

This computer starts up the older way (BIOS)

Setup said: “This computer starts up an older way”The firmware starts Windows in the older mode (“Legacy” or “CSM”), from a disk with an MBR partition table.

Why AurOS needs the newer way (UEFI): the first time AurOS starts, it starts through a one-time start entry. If anything goes wrong, this computer goes straight back to Windows by itself. The older way has no such entry, so Setup refuses rather than risk a computer that starts nothing.

Windows can switch over without being reinstalled, with Microsoft’s own MBR2GPT tool (Windows 10 version 1703 and later, and Windows 11). Nearly every computer made since about 2012 can start the newer way.

Check first

  1. Press Start, type System Information, and open it. BIOS Mode says Legacy. If it already says UEFI, this isn’t the reason: run AurOS Setup again.

  2. Do the steps in First, for any of these fixes.

The switch

MBR2GPT has no window of its own. This is the only fix on this page that needs typed commands.

  1. Press Start, type Command Prompt, then choose Run as administrator.

  2. Check that the disk can be converted:

    mbr2gpt /validate /allowFullOS

    It must end with:

    MBR2GPT: Validation completed successfully

    If it says “Validation failed”, stop here

    Nothing has been changed. The usual cause is that the disk already has four partitions, and the tool needs room for one more (the new start-up partition). Don’t delete partitions to make it pass unless you know exactly what each one holds. A recovery partition from the maker is often one of them. Leave this computer on Windows.

  3. Convert it:

    mbr2gpt /convert /allowFullOS

    It ends with MBR2GPT: Conversion completed successfully and a reminder to switch the firmware to UEFI. The tool is made to leave Windows’ files alone. It rewrites the partition table and adds a small start-up partition.

  4. Restart and open the firmware settings. Change the start-up mode from Legacy (or CSM) to UEFI. Makers word it differently: Boot Mode: UEFI, Boot List Option: UEFI, CSM Support: Disabled, Launch CSM: Never. Secure Boot can be on or off; AurOS works either way. Save and exit (often F10).

  5. Windows starts as before. In System Information, BIOS Mode now says UEFI.

  6. Run AurOS Setup again from the Downloads folder.

If Windows doesn’t start after the switch

Open the firmware settings again. Check that UEFI is chosen and that Windows Boot Manager is first in the start order. Don’t switch back to Legacy: the disk is now the newer kind, and Legacy mode can’t start it. If Windows still won’t start, use Windows’ own recovery from a Windows installation USB stick: Repair your computer → Startup Repair.

Microsoft describes the tool, with every condition it checks, on its own page called “MBR2GPT.EXE”.

AurOS can’t see this computer’s drive (Intel RST or VMD)

Setup said: “AurOS can’t see this computer’s drive”The drive Windows is on sits behind Intel’s storage driver, in a mode that hides it from other systems: RAID On (Intel Rapid Storage Technology, “RST”), or Intel’s VMD controller on newer laptops.

Why AurOS needs it changed: in that mode, Linux, and so AurOS, can’t see the drive at all. One firmware setting presents the drive the standard way (“AHCI”, or plain NVMe). Windows works the same afterwards, with Microsoft’s standard driver instead of Intel’s. The setting doesn’t change anything stored on the drive.

Check first

  1. Right-click Start, open Device Manager, then open Storage controllers. It lists an Intel controller with RST, RAID, Premium or VMD in its name.

  2. Before changing anything, look for these two

    • Intel Optane memory acceleration. If the Intel Optane Memory and Storage Management program shows it switched on, switch it off there first and let it finish. Then carry on.
    • Two or more drives combined into one (a RAID 0, 1, 5 or 10 “volume”, shown in Intel’s program). If there is one, stop here. Switching the mode would make that combined drive unreadable. Leave this computer on Windows.

  3. Do the steps in First, for any of these fixes, including the password.

The switch

Changing the setting alone would stop Windows from starting, because Windows would look for Intel’s driver. The safe way is to have Windows start once in Safe Mode, which picks up the standard driver by itself:

  1. Press Start, type System Configuration, and open it. On the Boot tab, tick Safe boot, leave Minimal chosen, and press OK. Choose Exit without restart.

  2. Open the firmware settings (see the first section). Find the storage setting and change it:

    • SATA Operation, SATA Mode or Storage Controller Mode: from RAID On (or Intel RST Premium) to AHCI; or
    • on newer laptops, VMD Controller or Enable VMD: switch it off.

    Some makers keep it under Advanced, Storage or System Configuration. Save and exit.

  3. Windows starts in Safe Mode (a black background with “Safe Mode” in the corners). Sign in, with the password if the PIN is refused. Open System Configuration again, untick Safe boot on the Boot tab, press OK, and choose Restart.

  4. Windows starts normally. In Device Manager, Storage controllers now shows Standard NVM Express Controller or Standard SATA AHCI Controller.

  5. Run AurOS Setup again from the Downloads folder.

If Windows doesn’t start, or keeps restarting, after the change

Open the firmware settings and put the storage setting back as it was (RAID On, or VMD on). Windows starts again with Intel’s driver; nothing on the drive was changed. If it starts in Safe Mode, open System Configuration, untick Safe boot, and restart. Then leave this computer on Windows.

AurOS would have no internet here

Setup stops, before it changes anything, on a computer whose only way online is a Wi-Fi card AurOS can’t use yet, and which has no socket for a network cable. Most often it is a Broadcom card (BCM4352, BCM4360 and the like) that only works with a program from Broadcom, which can’t be installed on a computer that has no internet yet. Without a way online AurOS couldn’t even fetch its own updates, so Setup says so first.

What fixes it: a USB Wi-Fi stick with a MediaTek MT7612U, MT7921 or MT7601U chip (which sticks have them), plugged in before Setup starts, or while its page is open: Setup checks again by itself every few seconds. A network cable does too, on a computer that has the socket. Buy by the chip, not by the name: makers change the chip inside a model between versions.

The list has been checked against the system AurOS carries, but it has not yet been tried stick by stick on a real computer (that is part of the lab’s hardware campaign), so keep the receipt.

Setup’s Save a report for a helper button (on the page where it can’t go on) writes AurOS-report.txt to the Desktop: the Wi-Fi card, the sound, the camera, the printers, as Windows names them.

How much room AurOS needs

AurOS needs at least 28 GB of empty space on the Windows drive, and uses up to 40 GB. Windows keeps 20 GB or more free when there is room, and never less than 8 GB. Setup shows both numbers before it changes anything.

Which USB Wi-Fi stick to buy

If this computer’s own Wi-Fi does not work with AurOS, a USB Wi-Fi stick can take its place. It has to be a stick whose chip AurOS already has a driver for. Each chip below was checked against the list of chips in AurOS’s own kernel (Linux 6.8 and 7.0), including the firmware that driver needs.

Buy by the chip, not by the name. Makers change the chip inside a model between versions without changing its name. If a product page does not say which chip is inside, do not buy it. Where a version is shown below, only that version.

None of these has been tried on a real computer with AurOS yet; that is part of the lab’s hardware campaign. Keep the receipt.

Plug the stick in, then open AurOS Setup again: it reads the chip itself, so it does not matter that Windows may say it has no driver for it.

MediaTek MT7612U (fast: 2.4 and 5 GHz, USB 3, “AC1200”)

Driver mt76x2u.

  • ALFA AWUS036ACM
  • Panda Wireless PAU0D
  • NETGEAR A6210

MediaTek MT7921AU (newest: Wi-Fi 6 and 6E, 2.4 and 5 GHz, “AX1800” or “AXE3000”)

Driver mt7921u.

  • ALFA AWUS036AXML
  • NETGEAR A8000 (the AXE3000 one)
  • EDUP EP-AX1672
  • Fenvi FU-AX1800, only the one whose listing says MT7921 (Fenvi also sells a look-alike with a Realtek chip)

MediaTek MT7610U (medium: 2.4 and 5 GHz, USB 2, “AC600”)

Driver mt76x0u.

  • ALFA AWUS036ACHM
  • Panda Wireless PAU0B

MediaTek MT7601U (plain and cheap: 2.4 GHz only, “N150”)

Driver mt7601u.

  • TP-Link TL-WN727N, version 4 only
  • D-Link DWA-127, revision B1 only
  • ASUS USB-N10, version 2 only

Do not buy these

Realtek RTL8811AU, RTL8812AU, RTL8821AU and RTL8814AU sticks (the TP-Link Archer T2U Nano and many cheap “AC600” and “AC1200” sticks) are not on this list: their drivers are very new in the kernel and have not been tried on AurOS. A stick that does not name its chip may be one of them.

Other systems, and anything else

Other systems. AurOS Setup will later be able to put an official, unchanged Ubuntu or Linux Mint beside Windows, the same careful way. That isn’t ready yet.

If Setup stopped for a different reason, its own page says what can be done. Most of the other reasons (a drive that is failing, Windows on an ARM chip, full-disk encryption from another company) are ones AurOS won’t work around on purpose, because getting them wrong could cost the files on this computer.

To ask a question, or to tell us Setup stopped when it shouldn’t have, open an issue on the AurOS project page. Don’t include passwords, recovery keys or anything else private.

AurOS will never phone you. Nobody from AurOS will ever ask to connect to your computer, or ask for a card number, a password or gift cards. Anyone who does is not from AurOS.
