A preview of custom AurOS

Choose a starting point.

Pick the kind of computer you want, then choose how it looks. At the end, you can save those choices in a small recipe file.

This does not make an AurOS download yet.

The file records your choices for a builder or helper. Today’s AurOS-Setup.exe does not read it, and this page does not send it anywhere.

1What kind of computer is this for?

These are the five starting points already kept in the AurOS source code. A recipe is a request for one of them; it is not proof that a build is ready.

2How should programs be arranged?

Keep the starting point’s arrangement, or choose one of the four arrangements people can already pick in AurOS.

The school computer stays locked to one browser, so its arrangement cannot be changed.

3Which colours should it use?

Keep the starting point’s colours, or choose one of the five AurOS themes.

4Save the choices.

This recipe contains only the starting point, look and colours shown above. It contains no name, email address, note, command, web address or program list.

Want something outside these choices?

Things such as “make the screen brighter when the computer points north,” adding a program, or changing how the system works need new code and testing. This page does not pretend to accept them. The safe next step is to describe that work on the AurOS project page.
