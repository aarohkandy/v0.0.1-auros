Stuck? Here is what to do.

Close any window you are unsure about. Windows and your files are still there. In AurOS Setup, press Not now. It says: “Not now: AurOS Setup closes. Nothing has been changed.”

Then show this page to someone you trust, or print it for them.

For whoever is helping: fill in the two blanks on the sheet below, print it, and leave it next to the computer. It is the front page’s steps, on one sheet.

Putting AurOS on this computer

Helping you: Their phone:

Windows and your files stay. You can go back to Windows. Keep the charger plugged in the whole time.

  1. Get it

    On this computer, open @AUROS_ADDRESS@ and press Get AurOS.

    The browser asks if you trust it, because it doesn’t know AurOS yet. Edge: the three dots … next to the file → Keep → the small arrow beside the black Delete → Keep anyway (never Delete). Chrome: Download suspicious file.

  2. Open the file

    Windows shows a blue box, Windows protected your PC, because it doesn’t know AurOS yet. Press More info, then Run anyway. Then Yes when it asks to make changes.

    “Smart App Control blocked an app” instead? Then AurOS can’t go on this computer yet. Nothing was changed.

  3. Pick a look, then press Install AurOS

    AurOS checks the computer first, and says so before changing anything if it can’t go on it.

  4. It restarts once, by itself

    Leave it switched on until AurOS has started.

  5. “Does everything work?”

    Check the internet first. Yes, it all works: AurOS starts every time from now on. No, go back to Windows: Windows starts the next time this computer starts, and AurOS stays on it, with anything saved in it. Until you answer, Windows and your files are kept just as they were.

To start Windows

As the computer switches on, press the menu key (often F12, F9 or Esc; the maker’s logo often says which) and choose Windows Boot Manager.

To remove AurOS

In AurOS: Settings, then Put Windows back, then press Remove AurOS and put Windows back twice. Anything saved in AurOS goes with it, so copy what you want to keep onto a memory stick first.

A small button is hard to press? Press Tab until it has a thick outline, then press Enter. Shift and Tab go back.
