Get AurOS

Not sure which Windows you have? Press Get AurOS. Setup checks, and changes nothing if it can’t go on.

AurOS needs Windows 10 or 11, and this computer may have an older Windows. AurOS Setup checks first and tells you.

Download the Windows file anyway

Simple, the way you’d want it.

It asks what you’d like to do.

Internet, photos, your files. Each one is a big button with its name written on it, not a little picture to guess at.

The buttons you need never move.

Help, Wi-Fi, Bigger text and Turn off are always along the bottom. This page has the same bar. Try Bigger text.

Four looks. Pick the one that feels like home.

You pick one while AurOS goes on. To change it later, press Settings, then How this computer works.

Putting it on: three steps.

Your browser and Windows don’t know AurOS yet, so they ask if you trust it. Press the button in the numbered circle.

  1. Downloads

    AurOS-Setup.exe

    Keep

    1Step 1: Download it

    Press Get AurOS. Your browser asks if you trust the file. Press Keep, then Keep anyway.

  2. Windows protected your PC

    App: AurOS-Setup.exe

    Run anyway

    2Step 2: Say yes to Windows

    Open the file. Windows asks, maybe twice. Press Run anyway, then Yes.

  3. Ready to install

    Install AurOS

    3Step 3: Pick a look, then install

    AurOS Setup checks the computer and lets you pick a look. The computer restarts once, by itself.

See every screen, with pictures

Don’t like it? Go back.

After the restart, AurOS asks if everything works. Until you say yes, Windows and your files are meant to stay on this computer.

Press No, go back to Windows and Windows starts the next time. Nothing is deleted.

Questions people ask.

Is it free?

Yes. No ads and no subscription.

Will I lose my files?

AurOS is made to keep your files, but any change to a drive carries some risk. Copy the photos you treasure onto a memory stick first.

Will my Windows programs work?

No. AurOS has its own programs for the internet, photos, music and notes, and many more, free.

What if I get stuck?

Press Help at the bottom of this page. It opens a one-page guide to print for whoever helps you. AurOS will never phone you or ask for a card number, a password or gift cards.
