Is AurOS working today?

This page shows the latest check when your browser can run scripts. Nothing on it asks for anything or sends anything.

What is checked

Every 15 minutes, a computer we do not own asks each of these the way you would. If one stops answering, the person who looks after AurOS is told at once.

  • This website: not checked yet
  • The download (the Get AurOS button): not checked yet
  • The files Setup fetches after you open it: not checked yet
  • Updates for computers that already have AurOS: not checked yet
  • Get more programs (Flathub, run by someone else): not checked yet

If something here says it is not working

Nothing on this page changes your computer. Computers that already have AurOS keep working, but may not get updates while the part that sends updates is down. If the download is not working, try again in an hour. Setup does not change Windows until you press Install AurOS.
