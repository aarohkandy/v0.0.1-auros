## Product bugs found and fixed (each with a test that fails without it)

1. **BitLocker stayed paused after the first return to Windows** — `-RebootCount 2` assumed the
   restart into AurOS counts; Windows counts only its own starts. Now `-RebootCount 1`
   (`4341c46c`, `src/aurbridge/phases.c`; `tools/fasttest.sh` pins it). Safe because AurOS's
   menu has the firmware start Windows Boot Manager (measured like every morning) and nothing
   after the restart reads C:.
2. **`handover.sh` was not executable** (0644 since 1c1b77d4), so `answer.sh` never took the
   handover and fell back to writing into the locked C: (`d8c2dbfb`). `tools/handover-mounttest.sh`
   now fails on any script under `rootfs/usr` without its executable bit.
3. **`handover.sh` could not find AurOS's partition from inside `auros-answer.service`**:
   `ReadWritePaths=` makes `/var/lib/auros` a bind mount, which `findmnt` names
   `/dev/sda5[/var/lib/auros]`. Fixed with `findmnt --nofsroot` (`2550e7b3`);
   `tools/handoverlinuxtest.sh` runs prepare/finish through a bind mount (21/21, the new case
   red without the fix, checked in a privileged container on homebase).
4. **The restore refused every disk with a BitLocker partition** (`fde_guard`, rescue.c). It
   now refuses only when the restore would change that partition's extent, remove/add its
   entry, or write a saved section over it (`0e5cf018`). A BitLocker volume is captured as
   nothing (`rescue_capture`), so Windows' fast-path C: is left byte for byte. The September
   review's case (NTFS when saved, BitLocker now) is still refused: new `fasttest.sh` case,
   passing in stagekvm 41780979107.
5. **Windows' put-back task waited for a sign-in that had already happened** — the task that
   copies her files is triggered at logon, and she was signed in first. It is now also started
   right after it is registered (`4e7957d5`, `src/aurbridge/putback.ps1`; `tools/handovertest.ps1`
   checks it).
6. **Turn off could hang up to 30 minutes** (Ubuntu's unattended-upgrade-shutdown losing its
   SIGTERM when started in the same second as a shutdown) — fixed by the side session in
   `95518ec7`; 45/45 patched runs passed.
7. **Site over its 300 KB first-screen budget** (330 KB): hidden looks were lazy-loaded before
   `door.js` hid them; looks re-encoded at quality 72 (`c3ef6396`). 279 KB.
8. **`answer.sh` lost why saving failed** (its `putback.log` lives in `/run`); it now copies it
   into `/var/log/auros-answer.log` on failure (`846c64fb`).
