## Goal

Scams are the #1 real threat to her. Three controls, each with a test
that is shown to fail when the control is removed:

1. **Firefox policy** — HTTPS-only, Safe Browsing she cannot click
   through, dangerous downloads blocked, no telemetry, uBlock Origin
   force-installed, calm defaults.
2. **A page can never trap her** — an always-available "Get me out of
   this page"; Escape always works; beeping can be silenced.
3. **Remote-control programs** (AnyDesk, TeamViewer, RustDesk ...) —
   before one is installed: "Scammers ask people to install this. Only
   continue if YOU called someone you know."

### Why PackageKit slipped through (85ebcae) -- read this before touching the rule

PackageKit's policy file says `package-install-untrusted`, `package-downgrade`
and `package-remove` each **imply** `package-install`. So when polkit is asked
about an install it also asks those, with the same details -- and forge grants
`package-remove` (49-auros.rules). Our NO to `package-install` was then
overruled by the grant for `package-remove`. Reproduced under a real polkitd 124
(`polkit.sh` was red), seen in polkitd's debug log. The rule now gates every
`org.freedesktop.packagekit.package-*` action unless every id in `package_ids`
is already installed (last field `installed` or `installed:<where>`, which is
all a removal names). PackageKit passes polkit only `package_ids`,
`transaction_id` and the `polkit.*` message keys, so there is nothing else to
read.

### Firefox on the real browser (1bbe51e)

`tools/scamtest/firefoxlive.py` starts Mozilla's apt Firefox (158.0.1, what the
image carries) on the shipped file and asks it (Marionette). Findings that are
not obvious:

- `DisableDeveloperTools` really does close Marionette, so the check on the
  real file is "the port stays closed", and everything else runs on a copy
  minus that one policy.
- `Services.policies.status`: 0 inactive, **1 active**, 2 failed.
- The Terms-of-Use window ("By continuing, you agree ... sends diagnostic and
  interaction data to Mozilla") is hidden by `SkipTermsOfUse` (sets
  `termsofuse.acceptedVersion` above `minimumVersion`) AND, independently, by
  locking `datareporting.policy.dataSubmissionPolicyBypassNotification`
  (bisected with real screenshots). Both are in the file.
- The crash window ("Tell Mozilla about this crash" ticked, "Include the
  address of the page I was on" ticked, plus a crash ping) has no policy;
  `MOZ_CRASHREPORTER_DISABLE=1` stops the handler entirely. It comes from the
  `aurshell.service` drop-in, so every program the desktop starts inherits it
  (the desktop kills Firefox's connection on "Close this page", which Firefox
  treats as a crash).
- Python's `glob` `**` skips hidden folders: a check for files under
  `~/.config` with it passes on anything. The control crash (same crash
  without the env must leave a report) is what caught it.
- Pictures: `docs/shots/firefox/{tou,crash}-{before,after}.png`
  (`tools/scamtest/firefoxshots.sh`, Xvfb).

### How the pieces fit

- **Way out.** Escape ×3 within 2 s (while a program is in front and no
  panel is open), Ctrl+Alt+Delete (anywhere), or the
  "Get me out of this page" button at the top of Help (whenever a
  program is open) open guard.c's card. `guard_watch_key()` sees every
  key in main.c before media keys and before `session_key()`, so no
  page can swallow them. The sound is muted while the card is up
  (`guard_step()`, every loop pass) and restored to what it was however
  the card closes. "Close this page" sets `want_close_win = 2`, which
  main.c turns into `aurwl_win_kill()` (no polite ask). Firefox's
  `sessionstore.resume_from_crash=false` (policy) keeps the page from
  coming back. A kiosk gets none of it.
- **Install card.** polkit asks `40-auros-remote-access.rules` first for
  `org.freedesktop.Flatpak.app-install` (`ref`),
  `com.ubuntu.pkexec.gdebi.gtk` (`command_line`, not with `--remove`) and
  `org.freedesktop.packagekit.package-install` (`package_ids`). If the
  normalised text matches the keyword list it spawns
  `remote-access-gate NAME USER`: exit 0 if
  `/run/auros-remote-access/NAME` is hers and < 15 min old, else it
  sends the system-bus signal `org.auros.Guard.RemoteAccess(s NAME)` and
  exits 1 → polkit NO. aurshell (`guard_pump()`) shows "Before you
  install this"; "I called someone I know" writes the file (as her) and
  says "Now try installing it again."; "Don't install it"/Escape write
  nothing. Removal and updates are never gated.

## Known ceilings (honest)

- **Not yet run on a booted image.** polkitd there runs under systemd's
  sandbox (ProtectSystem=strict, PrivateNetwork, AF_UNIX only); the
  helper only reads `/run` and talks to the bus socket, which that
  allows, but it is unproven. Also unproven: what GNOME Software and
  gdebi show after the NO (gdebi `exec`s pkexec, so its window is gone;
  the card's "Now try installing it again" covers both), and that
  killing Firefox's Wayland connection ends it promptly (the existing
  second-press "Close this" relies on the same).
- A `.deb` is recognised by its file name (polkitd cannot read her home
  folder); a renamed file passes. A local `.deb` opened through PackageKit's
  InstallFiles carries NO `package_ids`, so polkit cannot see its name;
  such a file is unsigned and uses `package-install-untrusted`, which forge
  does not grant (so it asks for a password nothing can supply and fails).
  gdebi is not in the image.
- "Installed" is judged from the id's last field. An install never has it
  (apt cannot install the version that is current), but that is PackageKit's
  convention, not polkit's.
- `MOZ_CRASHREPORTER_DISABLE` is not set for a Firefox from Flathub (its own
  sandbox and environment); that one also ignores `/etc/firefox/policies`. Scam calls send her to the vendor's
  real download, which keeps its name.
- `flatpak install --user` and `.flatpak` bundles do not pass through
  this rule (no terminal for her; bundles are not granted at all).
- Her "yes" lasts 15 minutes for that one program and cannot be revoked
  early (the helper cannot write). Gone at restart.
- The signal is read once per main-loop pass (idle wait ≤ 1 s), not
  from `poll()`.
- Super/Home: Super chords already always reach the desktop (main.c);
  Super alone goes Home only in some looks. Not changed here.

## Traps

- `/etc/firefox/policies/policies.json` wins over the install's
  `distribution/policies.json`, so ours carries `DisableAppUpdate`.
- Preferences policy accepts only allowed prefixes; others are dropped
  silently. firefoxpolicy.py checks against Firefox's own list.
- `/run/auros` is aurshell's RuntimeDirectory (0700, removed on stop);
  `/run/auros-guard` is S1's safe-mode state. The consent dir is
  `/run/auros-remote-access` (1777, sticky) on purpose.
- polkit rules are ES5 (duktape): no `=>`, `let`, `const`, template
  strings — remoteaccess.js checks.
- Two stopped installs in one loop pass: the card shows the later one.
- Harnesses that link foot.c must not need guard.c: foot.c only sets
  `c->guard_open`.
