## Traps

- `strchr(s, c)` with `c` > 0xFF: the int is cut to a char. Guard `c < 0x80`.
- Every lookup table walked to NULL must end in NULL (tests prove it now).
- macOS `cc` builds and runs the core tests; main.c needs Linux (homebase,
  docker image `auros-w1:dev` = auros-s3-fuzz + libdbus-1-dev).
