## Facts the next engineer must know

- **The cloud's schema is the contract**: `docs/wish-v1.schema.json`. The
  device's emoji allowlist is generated from it and `tools/wishtest-schema.py`
  fails if they differ; it also feeds the validator a document for every
  shape in the schema (142) and requires acceptance. The device is stricter in
  two places on purpose (a change of 0; `until` on an `off`).
- **Password fields (done, see "text-input-v3" below)**: aurwl now speaks
  `zwp_text_input_v3` (`src/aurwl/textinput.c`, linked only with wishes=on) and
  `wishhook.c` holds in secret fields. LIMITS, found by testing a real GTK3
  program (`tools/wishtest-gtk`): a GtkEntry with visibility off announces an
  ordinary field, so the matcher also refuses by program (polkit, pinentry,
  keyrings, password managers) and by window title (password, passphrase,
  sign in, code, ...). Firefox: not yet checked in a booted image (needs
  P/PARITY's harness): expected to send purpose=password for
  `<input type=password>` because its GTK code sets GtkInputPurpose from the
  HTML type; until that is seen, a browser with no announced field is held.
- Camera/microphone holds are looked for by the daemon itself (`io_holds` in
  main.c: `/proc/*/fd` → `/dev/video*`; `/proc/asound/*/pcm*c/*/status`
  RUNNING), only at the moment something is about to be shown.
- curl cannot read its `--config` from a pipe by path; config goes on stdin
  (`--config -`), body on descriptor 10 (`@/dev/fd/10`). The token is never in
  argv (test: `token_not_in_ps`).
- Test hooks exist only in the `-DAURWISH_TEST` build (paths from the
  environment, plain http, `inject`, `AURWISH_POW_BITS`). The hardened build
  has none (`OVERRIDE()` macro in main.c).
- `list` replies can be long: engine → shell lines may be up to 64 KB, shell →
  engine 4096 (AI.md §3.7 says so).

## Traps

- `strchr(s, c)` with `c` > 0xFF truncates the int to a char (U+202E became
  `.`). Guard `c < 0x80`.
- Every lookup table walked to NULL must end in NULL.
- `fcntl(fd, F_DUPFD, 10)` returns the next free number ≥ 10, not 10.
