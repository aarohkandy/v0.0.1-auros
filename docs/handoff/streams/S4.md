full-screen AurOS page at start (TPM 2.0 + PIN; an honest no-TPM
fallback), a 24-number rescue code she can keep on paper, Adiantum

## Measured facts (systemd 255.4, cryptsetup 2.7.0, noble)

- systemd's TPM token returns -131 for a wrong PIN, for TPM lockout
  AND for a cleared/different chip; -ENOENT for a PCR mismatch. The page
  reads the chip's own lockout counter before/after each try to tell
  them apart (THEFT.md section 3).
- The token plugin ignores `$SYSTEMD_TPM2_DEVICE`; it takes the device
  from its params struct (systemd 255 layout), used only in tests
  (`AURLOCK_TPM2_DEVICE`).
- LUKS2 refuses keyslot/token changes while online reencryption runs:
  set-pin exits 3 until the pass is over (the desktop must wait for it).
- `systemd-cryptenroll` cannot start from a TPM slot; `aurlock-pin
  --add-key` uses libcryptsetup's keyslot-context API to add a one-time
  passphrase authorised by TPM+PIN (change-pin, new rescue code).
- Online encryption with data shift works in 2.7.0: init ~1 s, pass
  ~6 s for 480 MB on homebase.

## Traps

- NEVER SIGKILL `cryptsetup reencrypt` on homebase (or any shared
  host): killed mid-hotzone it leaves a dm device suspended and every
  `sync` on the host hangs (it froze other streams' tests once; fixed
  with `dmsetup resume <name>-hotzone-*`). Power cuts belong in the VM.
- homebase has a real vTPM (/dev/tpm0, /dev/tpmrm0) and privileged
  containers see it: theftunit deletes the container's nodes first and
  points every call at swtpm. Never run TPM tools there unguarded.
- Loop devices and dm names are host-global: unique names, and clean up
  by backing file (`losetup -j`).
- In a privileged container `$$` is 1; don't build names from it alone.
- `$(func)` runs in a subshell: globals it sets (loop lists) are lost.
- grub cannot read the LUKS2 root: boot files must be on the EFI
  partition before the root is encrypted (`lockctl prepare` does
  boot-sync + stubs that fall back to the root's menu).
- Do not install `cryptsetup-initramfs` (its console prompt would
  replace the page).
