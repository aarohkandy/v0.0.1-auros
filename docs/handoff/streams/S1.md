## Traps

- Don't edit the shared main checkout; work in a worktree (`wt-s1`).
- Python has NO `socket.SOCK_DCCP`: a check written with it passes vacuously
  (AttributeError → "refused"). The controls-removed boot is what caught it.
- avahi keeps two random high UDP ports for its own unicast questions; allow
  avahi by process name (`ss -p`), not by port.
- Without zram+earlyoom the VM may never answer again after the hog: the hog
  runs last, after `sync`, and the host gives up 300 s after `hog-start`.
- `nft -c -f` needs root/netlink; test locally as root.
- earlyoom `EARLYOOM_ARGS` single quotes are unquoted by systemd.
- avahi `disable-publishing=yes` also blocks local services from publishing.
- slirp hostfwd accepts the HOST side immediately; the probe looks for a banner
  from the guest listener, never for a successful connect().
- `systemctl is-system-running --wait` would deadlock on a oneshot harness in
  multi-user.target: the harness unit is Type=simple and polls.
- Privileged containers on homebase leave root-owned files in the bind mount:
  clean `~/work/auros/s1/tmp` with `docker run ... rm -rf`, not by hand.
