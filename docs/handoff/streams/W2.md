## How to render and test (homebase)

Scratch scripts live outside the repo, in the lead's scratchpad (`w2/`):
`h` (ssh), `sync` (rsync wt-w2 -> `~/work/auros/w2/`), `dk` (run in the
`auros-c:dev` container with the repo at /w, out at /w/out), `mk.sh` (builds
aurshell like forge), `sheet.sh` (renders every state for each look; needs
`-v /usr/share/fonts/truetype/noto` for the emoji), `montage.sh`, `regress.sh`
(stream C's harnesses), `uitest.sh`. If lost: the container is
`docker run --rm --memory 4g -v $PWD:/w -w /w auros-c:dev` with fonts at
`/usr/share/auros/fonts` (Inter symlinks); the build line is `build/forge`'s.
`tools/wishsheet.c`'s header has the compile line:
`/tmp/wishsheet <shell.conf> shells/<look>.shell <outdir> [w h [scale]]`.
