## Socket (proposal to W1; W1 owns it — if W1 writes its own spec, W2 follows it)

- `$XDG_RUNTIME_DIR/aurwish.sock`, AF_UNIX SOCK_STREAM, the engine listens and
  checks `SO_PEERCRED` uid == its own. One JSON object per line, UTF-8,
  at most 4096 bytes a line, both directions.
- **The shell never talks to the cloud.** Only the engine does (it has the caps,
  the token, and validates every wish anyway), so CL has one client.

Shell → engine (every request carries an integer `id`; replies echo it):

```
{"op":"wish","id":1,"text":"Fill my screen with potatoes when I type potato","lang":"en","voice":false}
{"op":"cancel","id":1}                      she pressed Cancel while waiting
{"op":"confirm","id":2,"pending":"p7"}      "Yes, do that"
{"op":"discard","id":3,"pending":"p7"}      "No, thanks"
{"op":"list","id":4}
{"op":"enable","id":5,"wid":"w3","on":false}
{"op":"remove","id":6,"wid":"w3"}
{"op":"all_off","id":7}
{"op":"typed","word":"potato"}              the compositor matched a registered word (no reply)
```

Engine → shell replies:

```
{"id":1,"kind":"wish","sentence":"<the device's own sentence>","pending":"p7"}
{"id":1,"kind":"answer","text":"...","sentence":"<optional offer>","pending":"<optional>"}
{"id":1,"kind":"cannot","text":"I can't do that yet, but I can ..."}
{"id":1,"kind":"error","error":"offline|busy|resting|limit|refused|broken","text":"<optional plain line>"}
{"id":2,"kind":"done"}
{"id":4,"kind":"list","wishes":[{"wid":"w3","sentence":"...","enabled":true}],"all_off":false}
```

Engine → shell events (no `id`), only for what the shell draws or owns:

```
{"ev":"fill","emoji":"🥔","seconds":3}   or   {"ev":"fill","text":"HELLO","seconds":3}
{"ev":"message","text":"...","seconds":10}
{"ev":"remind","text":"Time to take your pills"}
{"ev":"words","words":["potato"]}          the whole trigger list; on connect and on every change
{"ev":"changed"}                           the list changed: My wishes refreshes
{"ev":"shell","do":{<one validated v1 action: set_look | set_text_size | open_app | open_website>}}
```

Everything else (speak, play_sound, brightness, volume, night_light,
wallpaper, install_program) stays in the engine. For `speak` the engine runs
W2's on-device voice: `aurvoice say "<text>"`.

The shell caps a fill at 10 s and drops every overlay at the first key or
click whatever the engine sends (belt and braces with the engine's caps).
