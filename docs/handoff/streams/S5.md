## Traps

- The shared stash list: `git stash list` shows other worktrees' stashes.
- `aptrepo.yml` gate: `[apt` in the SUBJECT publishes. Never put it in a
  subject by accident.
- `/usr/lib/auros/bootchain-apt` runs after every dpkg run (52auros-bootchain);
  never run real AurOS packages in a test container with the host's /sys.
- unattended-upgrades picks the highest version from ANY allowed origin:
  Ubuntu's release pocket is allowed by default, and Ubuntu's firefox is a
  snap stub with an epoch. forge's pin_no_snap (-1) is what stops it; the
  Firefox test replicates that pin.
- forge has two `preferences.d/mozilla` heredocs (apt and PPA routes).

## How to verify

- `docker run --rm -v $PWD:/w:ro -w /w ubuntu:24.04 bash -c 'apt-get update && apt-get install -y unattended-upgrades gnupg gpgv python3 hello xz-utils && bash tools/updatetest.sh'` (and `--break=X`, each must exit 1).
- `bash tools/updatepolicytest.sh firefox` in the same kind of container (with curl, ca-certificates, procps).
- `sudo bash tools/updatepolicytest.sh static work/forge/desktop/rootfs`.
- aptrepo.yml runs: `gh run list -R aarohkandy/v0.0.1-auros -w aptrepo`.
