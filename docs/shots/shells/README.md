# The desktop as she sees it (stream C, Light theme, real shell code)

Rendered by `tools/journeytest.sh <dir>` (the shipping paint code against
the programs `build/forge` ships) and `tools/setsheet.c` / `tools/netsheet.c`.
Every look at 1366x768 and 1024x600: `asks` (first start), `desktop`,
`online` (the Wi-Fi page), `ready` (a program was installed: the card),
`opens` (the program opened). `settings-` and `wifi-` are contact sheets of
every page. Light theme, Atkinson Hyperlegible at the spec's sizes. Regenerate after any
change to the shell; do not hand-edit.
